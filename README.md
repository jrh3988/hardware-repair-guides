Step-by-step hardware repair guides written for beginners, based on repairs I performed myself. Each guide uses one action per step, a photo wherever something needs to be found or removed, and a check at the end to confirm the repair worked. The format is inspired by iFixit, with extra detail where beginners tend to get stuck.

I’m building toward a career as a device technician, and I’ll add new guides and devices as I work on more repairs.
